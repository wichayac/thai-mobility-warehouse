Thai Mobility Data Warehouse

A personal data engineering project exploring how to ingest, validate, transform, and analyze GPS mobility data using Python and SQL.

Project Goals

Practice building reliable data ingestion pipelines.

Validate raw GPS records and identify data quality issues.

Verify file integrity using SHA-256 hashing.

Develop an analytical data warehouse in later milestones.

Current Progress

Milestone 1: CSV inspection, data type conversion, and GPS validation.

Milestone 2: File copying and SHA-256 integrity verification (in progress).

Technologies

Python, CSV, pathlib, shutil, hashlib

Status

Work in progress — developed as a learning project for data engineering.
